BERT Model Deep Dive

Bidirectional Encoder Representations from Transformers

  • Developed by Google (2018).
  • Uses an Encoder-Only Transformer architecture.
  • Processes text bidirectionally. Traditional models read left-to-right (like GPT) or right-to-left. BERT reads the entire sequence of words at once.
  • This allows the model to learn the context of a word based on all of its surroundings.

Inside the BERT Encoder Block

Each Encoder block in BERT contains two main sub-layers. The output of one block feeds directly into the next.

  • Multi-Head Attention: Allows the model to look at other words in the sentence.
  • Add & Norm: Residual connections to prevent vanishing gradients.
  • Feed Forward: A standard neural network applied to every position separately.

The Self-Attention Mechanism

How BERT determines which words are relevant to each other.

Query (Q)
Key (K)
Value (V)
↓
MatMul (Q x K)
↓

↓

Concept: Q is what you are looking for, K is what the word possesses, and V is the actual content. Softmax(QxK) creates a score of how much focus to put on other words.

Pre-training 1: Masked Language Model (MLM)

To train bidirectionally without the model "seeing" the answer, BERT masks 15% of the words in a sequence and tries to predict them.

The 80-10-10 Rule for the chosen 15%:

  • 80%: Replaced with the [MASK] token.
  • 10%: Replaced with a random word (forces model to rely on context).
  • 10%: Kept unchanged (helps model maintain representation of actual words).

Pre-training 2: Next Sentence Prediction (NSP)

BERT learns relationships between sentences, crucial for Question Answering.

  • Model receives pairs of sentences as input.
  • Training Data Split:
    • 50% of the time, Sentence B is the actual next sentence (Label: IsNext).
    • 50% of the time, Sentence B is a random sentence from the corpus (Label: NotNext).
  • The model outputs a binary classification prediction.

Special Tokens:
[CLS] is added at the start. Its final state contains the sequence classification info.
[SEP] is used to separate Sentence A from Sentence B.

BERT vs. GPT

How does Google's BERT differ from OpenAI's GPT models?

Feature BERT GPT
Architecture Transformer Encoder Transformer Decoder
Context Bidirectional (Looks left & right) Unidirectional (Looks left-to-right)
Objective Understanding (Classification, QA, NER) Generation (Writing, Synthesis)

Code 1: Loading Pre-trained BERT

Using the Hugging Face transformers library to generate hidden states.

from transformers import BertTokenizer, BertModel
import torch

# 1. Load Pre-trained Tokenizer and Model
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

# 2. Tokenize Input Text
text = "Artificial Intelligence is transforming the world of technology."
inputs = tokenizer(text, return_tensors="pt")

print("Original Text:", text)
print("Tokens:", tokenizer.convert_ids_to_tokens(inputs['input_ids'][0]))
print("Input IDs:", inputs['input_ids'])
print("Attention Mask:", inputs['attention_mask'])

# 3. Generate Contextual Output
outputs = model(**inputs)
last_hidden_states = outputs.last_hidden_state

print("\nHidden state shape:", last_hidden_states.shape)
print("Meaning of shape: [Batch Size, Sequence Length, Hidden Size (768 for BERT-base)]")

Code 2: Fine-Tuning for Sentiment Analysis

Custom PyTorch architecture wrapping BERT for a classification task.

from torch import nn
from transformers import AutoModel

# Load model and freeze pre-trained layers
bert = AutoModel.from_pretrained('bert-base-uncased')
for param in bert.parameters():
    param.requires_grad = False

class BERT_architecture(nn.Module):
    def __init__(self, bert):
        super(BERT_architecture, self).__init__()
        self.bert = bert
        self.dropout = nn.Dropout(0.2)
        self.fc1 = nn.Linear(768, 512)
        self.fc2 = nn.Linear(512, 2) # 2 output classes - returns raw logits

    def forward(self, sent_id, mask):
        outputs = self.bert(sent_id, attention_mask=mask)
        cls_hs = outputs.pooler_output # Get the [CLS] token representation
        x = self.dropout(torch.relu(self.fc1(cls_hs)))
        return self.fc2(x) # Return logits so CrossEntropyLoss handles softmax

Code 3: Named Entity Recognition (NER)

Using Hugging Face's pipeline for out-of-the-box entity detection.

from transformers import pipeline

# Initialize NER pipeline with a pre-trained NER model
print("Loading NER pipeline...")
ner = pipeline(
    "ner",
    model="dslim/bert-base-NER",
    aggregation_strategy="simple"
)

text = "Microsoft Corporation is headquartered in Redmond, Washington, USA."
print("\nInput Text:", text)
print("-" * 50)

entities = ner(text)

# Extract and print identified entities
print("Identified Entities:")
for entity in entities:
    print(f"[{entity['entity_group']}] -> '{entity['word']}' (Confidence: {entity['score']:.4f})")
