# Module 08: Transformers and BERT Foundations

This module focuses on the architecture of modern Transformer encoders and the BERT foundation model.

## Contents
- `01_bert_fundamentals.ipynb`: Hugging Face Transformers pipeline, tokenization, hidden states extraction, NER, and custom classification heads.
- `bert_flashcards.html`: Visual interactive explanations of BERT encoder blocks, Masked Language Modeling (MLM), and Next Sentence Prediction (NSP).
